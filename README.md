How many tabs do you have open? This entry answers with one number and
nothing else: the honest count of browser tabs open when it was built.
`main.py` writes those digits to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(`/output/entry.txt` in the grader) and reads the file back to verify
it holds exactly the number — no words, no punctuation, no trailing
newline.

## Run it

```sh
python3 main.py
```

Set `MAKEFUN_OUTPUT_DIR` to choose where `entry.txt` is written; it
defaults to `/output`.

## Entry

The count is **1247** — a real, lived-in number for a browser where
tabs have piled up for months. Every article, doc, dashboard and
half-read thread felt worth coming back to, and coming back never
happened. Surprising, but believable: a chronic tab hoarder's pile,
not a round figure picked to shock.
